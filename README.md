# 🚀 Automated Business Intelligence Dashboard Generator
### 🤖 AI-Driven CSV-to-Executive Dashboard System  
n8n • Python • Pandas • Chart.js • HTML

An AI-powered Business Intelligence engine that transforms any uploaded CSV dataset into a structured, executive-level analytics dashboard automatically.

No manual configuration. No dataset dependency. Fully automated.

---

## 🔍 Problem Statement

Traditional dashboards are:

- ❌ Manually configured
- ❌ Dataset-specific
- ❌ Time-consuming to build
- ❌ Dependent on tools like Power BI or Tableau

Modern businesses need a smarter solution.

This project introduces a self-adaptive BI engine that works for **any dataset** without hardcoding.

---

## ⚙️ Solution Architecture

### 🖥 Frontend Layer

- CSV upload interface
- Dynamic dashboard rendering
- Power BI-inspired executive layout (1280x720)
- Chart.js-based visualization
- Professional theming system

---

### 🔄 Automation Engine (n8n)

- Webhook-based CSV ingestion
- Automated workflow orchestration
- KPI and chart logic generation
- JSON response pipeline for frontend rendering

---

### 📊 Data Processing Engine (Python + Pandas)

- Automatic numeric column detection
- Statistical summary computation (mean, min, max)
- IQR-based anomaly detection
- Dataset-type inference
- Intelligent KPI identification
- Automated chart recommendation engine

---

## 📈 What the System Does Automatically

- ✔ Detects dataset type (Finance, Retail, Entertainment, Demographics, etc.)
- ✔ Generates relevant KPIs dynamically
- ✔ Builds category, distribution, and trend charts
- ✔ Creates executive summary insights
- ✔ Auto-generates dashboard titles
- ✔ Applies professional executive layout
- ✔ Outputs presentation-ready dashboards

No hardcoding.  
No manual KPI setup.  
No dataset dependency.
